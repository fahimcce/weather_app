# 🌤️ Weather App

A responsive and modern Weather Web Application built with **Next.js**. Get real-time weather updates for any location worldwide using this sleek, intuitive interface.

## 🚀 Features

- 📍 Search weather by city name
- 🌡️ Real-time temperature, humidity, wind speed
- ⛅ Dynamic weather icons and status
- 🌍 Supports global locations
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Built with Next.js and modern React hooks

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS ,Redux
- **API:** OpenWeatherMap API

## 🔗 Live Demo

👉 [Visit the Live App](https://digidenweather.vercel.app/)

## 🔧 Getting Started

### Prerequisites

- Node.js >= 15
- npm or yarn

### Installation

```bash
# Clone the repo
git clone https://github.com/fahimcce/weather_app

# Navigate to project directory
cd weather-app

# Install dependencies
npm install
# or
yarn install

# Run app
npm run dev
# or
yarn dev
```
